# Haullk

Building GeoPrizm: an open-source dashboard for tracking international relationship trends from GDELT news event data.

## Featured project

[GeoPrizm](https://www.geoprizm.com) turns structured global news events into a readable 0-100 relationship index, trend segments, report clues, and AI-assisted Chinese explanations.

- Source: [relationship-temperature](https://github.com/Haullk/relationship-temperature)
- Focus: international relations, GDELT, geopolitics, data visualization, news analysis
- Current pairs: China-US, China-Russia, China-EU, China-Japan, China-India, US-Iran, US-Russia, Russia-Ukraine
- Boundary: reflects media event signals, not official diplomatic positions

If GeoPrizm is useful or interesting, a star on the repository helps more people find it.
